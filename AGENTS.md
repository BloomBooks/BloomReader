# Agent instructions for BloomReader

## Issue tracker

This project tracks work in **Bloom's YouTrack**. Ticket ids look like `BL-1234` and appear in
branch names and commit messages when a branch has a card. Agents talk to the tracker through the
**`youtrack-api`** skill (and its `youtrack-*` companions). A branch whose name carries no `BL-` id likely has no card and you can likely skip card-related steps for it.
